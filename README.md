# Java Day 29 - Reverse Array Elements

This Java program prints the elements of an array in reverse order.

## Example

Original Array:
```text
10, 20, 30, 40, 50
```

Output:
```text
50
40
30
20
10
```

## Concepts Used

- Arrays
- `for` loop
- Array indexing
- `length` property
- Decrement operator `--`

## How It Works

The loop starts from the last index of the array and moves backward until it reaches index zero. Each element is printed in reverse order.

## What I Learned

I learned how to access and print array elements from the last index to the first index in Java.
